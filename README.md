# United Identity

Yeni arxitektura:

**Mənbələr (WEB / Telegram) → Yoxlama modulu → Paylaşım modulu**

## 1. Mənbələr
Hər veb saytın və hər Telegram kanalının ayrıca modulu olacaq. Modul yalnız həmin mənbəni oxuyur və standart paket qaytarır.

## 2. Yoxlama modulu
İki səviyyə:
- **Texniki yoxlama:** URL, media, mənbə formatı və texniki xətalar.
- **Vizual/məzmun yoxlaması:** Azərbaycan dili, şəkil/video, post strukturu və Telegraph Ətraflı qaydası.

Yoxlamadan keçməyən material paylaşım moduluna buraxılmır.

## 3. Paylaşım modulu
Yalnız yoxlanmış hazır postu Telegram-a göndərir.
KreaDIV formatı əsas götürülür.
**Ətraflı** linki yalnız telegra.ph səhifəsinə gedə bilər.

Hazırda mənbə sayı: **0**. Mənbələr bundan sonra individual qoşulacaq.
